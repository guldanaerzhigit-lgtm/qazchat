# QazChat — интерактивный макет

Статический макет мессенджера для компьютера и телефона.

## Запуск

Откройте `index.html` в браузере или подключите репозиторий к Cloudflare Pages. Для Cloudflare Pages выберите сборку без команды сборки; каталог вывода — `/` (корень репозитория).

## Что есть в макете

- список демонстрационных личных и групповых чатов;
- фильтр и поиск по списку;
- отправка сообщений в интерфейсе текущей вкладки;
- создание демонстрационного чата или группы;
- переключение светлой и тёмной темы;
- адаптивный интерфейс для мобильных экранов.

## Важно

Это только frontend-макет. Сообщения не доставляются другим людям и не сохраняются в базе данных. Firebase Authentication и Cloud Firestore ещё не подключены. Не вводите настоящие пароли или конфиденциальные данные.
